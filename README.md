# Jason S. Fillman

Systems and infrastructure engineer. I build working systems from a blank repo, fast, and then make them survive production. Rust by default, Kubernetes under most of it, agents at the keyboard.

Day job: Senior Systems & Infrastructure Engineer at Netflix Labs. Before that, research computing at Lawrence Berkeley National Laboratory. First Linux user group in Corpus Christi, at 17.

- **[caelus-r8](https://github.com/jsfillman/caelus-r8)** — A Kubernetes-native VST3 synthesizer: voice workers as pods, ZMQ + OSC + memory-mapped audio into a DAW. Rust, nih-plug.
- **[kluge](https://github.com/jsfillman/kluge)** — Slurm-style batch jobs on Kubernetes: `sbatch`-compatible scripts, ephemeral per-user clusters, results back on your desktop.

- **[caelus](https://github.com/jsfillman/caelus)** — The original Python synth suite: modular FM, distributed additive synthesis, and the first "every note is a pod" experiment.

Most recent work is in private repos. Ask.
